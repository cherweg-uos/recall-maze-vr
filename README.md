# Recall Maze VR

Hi. this is a project to create a VR experience of a series immersive mazes. instructions of how to solve a maze is given at the beginning of each maze. Each sequential maze has increase difficulty in terms of the amount of steps/directions that need to be followed in order to reach the goal.

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://recall-maze-vr.lovable.app
